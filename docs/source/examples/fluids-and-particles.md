# Fluids and particles (C++)

| Example | Demonstrates |
| --- | --- |
| `physics_fluid_debug_particles` | Fluid particle inspection |
| `physics_fluid_scale_container` | Fluid in a container |
| `physics_fluid_moving_splitter` | Dynamic fluid interaction |
| `physics_fluid_material_showcase_multi_env` | Fluid materials across environments |

The fluid examples share the regular runtime lifecycle; their differences are
scene authoring and particle/material configuration.
