# Surgical scenes and ultrasound (C++)

| Example | Demonstrates |
| --- | --- |
| `physics_soft_body_arc_needle_thread_kinematic` | Needle, thread, and deformable tissue |
| `physics_planar_hinge_cdcr` | Planar cable-driven continuum robot |
| `physics_rigid_spherical_cdcr` | Spatial cable-driven continuum robot |
| `physics_soft_particles_ultrasound_multi_env` | Batched soft tissue and ultrasound sensing |

Ultrasound requires an ultrasound-enabled build. The standard documentation API
build leaves this optional feature disabled.
