# Soft-body pushing

**Demonstrates:** particle-based deformable tissue, batched task execution, and
Torch vector-environment integration.

```bash
python examples/python/soft_body_pusher_torch_vector_env.py
```

Use this example when adapting a manipulation task around deformable geometry.
See also `examples/physics/soft_particles_multi_env.cpp` for a C++ multi-
environment particle scene.
