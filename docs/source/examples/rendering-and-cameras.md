# Rendering and cameras (C++)

| Example | Demonstrates |
| --- | --- |
| `graphics_camera_outputs` | RGB, depth, and segmentation camera outputs |
| `graphics_texture` | Texture resources and materials |
| `graphics_skybox_ibl` | Environment lighting |
| `graphics_transparent` | Transparent rendering |

Start with `examples/graphics/camera_outputs.cpp` when integrating renderer
outputs into an application or data-generation workflow.
