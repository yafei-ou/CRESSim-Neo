# PSM tasks

The PSM examples provide reusable surgical-instrument scenes.

```bash
python examples/python/psm_soft_grasp_torch_vector_env.py
python examples/python/psm_blood_suction_torch_vector_env.py
python examples/python/psm_env_viewer.py --tool-type large_needle_driver
```

Use soft grasping to study tissue interaction and blood suction to combine a
PSM with fluid. The viewer is a convenient authoring and visual-inspection
entry point.
