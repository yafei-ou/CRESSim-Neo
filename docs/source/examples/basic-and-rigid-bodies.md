# Basic and rigid bodies (C++)

| Example | Demonstrates |
| --- | --- |
| `physics_basic` | Runtime setup, rigid bodies, colliders, and stepping |
| `physics_rigid_joints` | Ball, hinge, spherical, and slider joints |
| `physics_mixed_shape_contacts` | Contact between collider shapes |
| `physics_large_array_multi_env` | Many environments in one runtime |

Start with `examples/physics/basic.cpp`. These examples establish the C++
authoring and stepping pattern used throughout the repository.
