CRESSim-Neo Documentation
=========================

CRESSim-Neo is a C++ GPU simulation engine for surgical robotics. Its Python
bindings expose the same runtime model for applications that need them.

Start with :doc:`Getting Started <getting-started/index>` to install an SDK or
binding. The :doc:`User Guide <guides/index>` explains the runtime model and
engine features; its concepts apply equally to C++ and Python.
